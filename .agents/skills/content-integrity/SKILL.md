# Content integrity and source control
1. Identify one concrete visitor question; write to answer it beside the actual tool, not to reach arbitrary word count.
2. Maintain source/claim evidence: URL, actual document inspected, publication/access date, applicability, asserted constant, limits and verified/disputed/unverified status.
3. Separate universal arithmetic from varying agronomic norms. If reliable norm missing, document as user input or stop unsupported recommendation.
4. Write concise Russian: meaning of fields, one worked example, formula, units, assumptions, interpretation and limits. Each paragraph must add new substance.
5. Remove boilerplate, invented testimonials, fake anecdotes, placeholder FAQ, repeated paraphrases, unverified numbers and unsupported promises.
6. Compare against calculator spec, test cases and overlapping pages to avoid contradictions and keyword cannibalization.
Exit: traceable claims, correct Russian and genuinely useful text; unsupported content → BLOCKED_UNVERIFIED_CONTENT.
