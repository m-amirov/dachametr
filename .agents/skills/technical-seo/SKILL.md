# Technical SEO of a utility site
1. Begin with verified search intent and existing routes; don't fabricate keywords or assume an app already exists.
2. One distinct calculation task → one canonical URL. Never scale pages by city, number, parameter, synonymous title or near-duplicate template.
3. Ensure indexable HTML carries a meaningful title/H1, task description, working form and independent utility; avoid empty client-only shells.
4. Check canonical, robots, sitemap, clean statuses, links, mobile parity, metadata and accidental noindex on actual built output.
5. Use schema.org only for genuinely matching content and required properties; never fabricate ratings, FAQs, products, offers or credentials. Validate rendered JSON-LD and supported rich-result types.
6. Test actual performance and summarize lab vs field metrics. Indexability is not proof of indexation, and indexing is not proof of rankings.
7. Record live tools, URLs, dates and evidence; if no Webmaster/Search Console access, mark those checks BLOCKED.
Exit: documented technical readiness for implemented routes, without made-up performance or traffic evidence.
