## Синтез

Rayon дал не палитру, а архитектурные принципы: «структура слева → свойства выбранного объекта → рабочая область → таблица для количеств». В Dachametr они переосмыслены как «зоны слева → выбранная зона и её измерительный разрез → BOM справа». Ограничение доменной модели сохранено: прямоугольник в центре — только габарит выбранной зоны, а не карта участка.

## Проверяемые границы

- Маркетинговая главная страница Rayon не использовалась как единственное доказательство: основа аудита — editor documentation, layers, tables, properties и V2 interface write-up.
- Никакой внешний font request или внешний image asset не добавлен.
- OpenDesign Cloud generation: `NOT RUN`; paid credits не использовались.
