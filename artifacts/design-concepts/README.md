# Три визуальные концепции «Дачаметра»

Это изолированный exploratory-слой на exact HEAD `90bb578291d6f9aeb935470ce4784e4f9ce4a8af`. Он не подключён к `src/`, не меняет рабочие расчёты и не является выбранным редизайном.

## Как открыть

При запущенном локальном Vite-сервере:

```text
http://127.0.0.1:4173/artifacts/design-concepts/index.html?concept=a&state=result
```

Параметры:

- `concept=a` — «Измерительная мастерская»;
- `concept=b` — «Современный садовый атлас»;
- `concept=c` — «Профессиональная расчётная студия»;
- `state=initial|editing|error|result` — состояние экрана.

В верхней панели есть переключатели направлений и состояний. Поля и кнопки — визуальные mock controls; рабочая математика остаётся в существующем приложении.

## Направления

### A — Измерительная мастерская

Точный спокойный инструмент: крупное чтение чисел, вертикальные акценты измерения, компактная ведомость и почти чертёжная сетка. Лучше всего отвечает задаче «ввести размеры → быстро проверить объём».

### B — Современный садовый атлас

Редакционный лист: полевая нумерация, профиль реальных размеров участка, serif-заголовки и спокойная зелёно-земляная палитра. Профиль намеренно не изображает карту и не утверждает расположение зон.

### C — Профессиональная расчётная студия

Плотная операторская панель: данные участка слева, BOM со сравнимыми колонками справа, статусы `DRAFT / CALCULATED / BLOCKED` и явный итоговый объём. Лучше всего подходит для нескольких зон и последовательной проверки закупки.

## Ограничения

Концепты не используют OpenDesign Cloud и не передают файлы проекта во внешние сервисы. Внешние референсы исследованы как принципы композиции, сравнительных таблиц и CTA; чужие скриншоты, логотипы, изображения и шрифты в репозиторий не копировались.
