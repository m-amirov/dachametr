# Dachametr — DESIGN.md

**Проектный контракт для OpenDesign и Codex**, версия 0.2 (локальный UI PR #11). Исходные дизайн-концепции: PR #10; проверяемый рабочий UI — PR #11. Дизайн не утверждён для публичной публикации.

## Продукт
Дачаметр — русскоязычный калькулятор участка, зон, грунта, песка и щебня. Главный сценарий: размеры участка → зоны → слои материалов → объёмы и ведомость закупки. Это не SaaS-лендинг; рабочие поля и расчётные результаты важнее рекламы, промоблоков и декоративных иллюстраций.

## Текущий baseline локального Vite-прототипа PR #11

Направление «Результат рядом» перенесено из статического визуального исследования PR #10 в отдельную ветку PR #11 на базе рабочего UI PR #8. Это **рабочая версия**, не окончательная визуальная приёмка владельцем.

Токены из `src/styles.css`:

- --canvas: #f4f6f0 (спокойная поверхность); --paper: #ffffff; --paper-soft: #fbfcf8.
- --ink: #14251f; --ink-soft: #365048; --muted: #62736a.
- --pine: #2f705d; --pine-dark: #1d4f40 — результат и числовые значения.
- --coral: #be4c2d; --coral-dark: #96391e — основные действия.
- --danger: #a53428 — ошибки. Запас, масса и закупка считаются только существующим доменным движком.
- Шрифтовый стек: системный sans-serif с кириллицей, без внешних сетевых шрифтов или копирования сторонних ассетов.

UX: компактная строка размеров, сводки зон с раскрываемым редактированием, материалы summary-first с явной кнопкой «Настроить», ведомость рядом на desktop и после редактора на mobile. Вся доменная модель и правила material_spec_id сохранены.

## Информационная архитектура
1. Чёткая цель расчёта и ввод площади участка на первом экране.
2. Зоны и слои с ясными связанными полями и устойчивыми ID; нельзя смешивать разные material_spec_id только по названию.
3. Видимые м, м², сотки, см, м³, л, кг, упаковки. Отдельно обозначать необходимый объём с запасом и фактически закупаемый объём.
4. Прозрачная ведомость (BOM) с группировкой сопоставимых материалов и объяснением округления.
5. Ясные пустое, редактируемое, ошибочное и успешное состояния. Ошибка в активной зоне блокирует итоговую закупку целиком.
6. Основные CTA: добавить зону/слой, выбрать материал, изменить параметры; не «Купить сейчас» и не «Подписаться».

## Характер
Современный инструмент расчёта и закупки с ясной числовой иерархией. Уместны функциональные шкалы, понятные прямоугольные формы и диаграммы слоёв, но никакой фальшивой карты расположения зон, псевдонорм или случайных листьев/3D-камней. Свободное пространство должно помогать восприятию, а не имитировать премиальную SaaS-страницу.

## Критерии качества
320/390/768/1024/1440 CSS px, 200% zoom, tablet landscape; русский длинный текст, editing с 1,, focus/caret, keyboard, error и BOM. Для изменения UI обязательны актуальные before/after в реальном браузере, с SHA, viewport, browser и состоянием; старые PNG из artifacts/ui-evidence/f6d4244 относятся к другому SHA и не являются доказательством текущего рендера.

## Референсы
Подробности в docs/design/reference-library.md. Принимаем принципы типографики/композиции, сравнения чисел и ясных действий, но не копируем чужие скриншоты, логотипы, продукты, pricing tiers и готовые UI. Нельзя автоматически менять палитру по внешнему шаблону.

## Визуальный характер — PR #12 (2026-11-14, локальный scope)

- **Распознаваемый знак:** планиметрическая геометрия в компактном векторном знаке вместо значка аналитики. Это абстрактный логотип, не изображение географического расположения зон.
- **Данные прежде декора:** ведомость с акцентным тёмно-зелёным блоком ключевого объёма, не новой hero-секцией.
- **Материалы в собственных цветах:** грунт `#9c7254`, песок `#d3a04b`, щебень `#7d8e99`. Всегда дублировать цвет названием материала и толщиной.
- **Схема слоёв:** только для зон с двумя или более корректно заполненными слоями; высоты пропорциональны точной пользовательской толщине `Exact` (через CSS flex-grow), порядок соответствует списку сверху вниз. Схема не показывает координаты зон и не даёт инженерных рекомендаций. Если валидация `fail-closed`, схема не выводится.
- **Mobile:** однострочная CTA «Добавить зону» при 320/390 px, перенос кнопки отдельной строкой ниже 340 px. Нет sticky-футера поверх экранной клавиатуры.
- **Границы:** `src/domain` не изменяется, нет новых webfonts, удалённых assets, сетевых API, публичных SEO URL или платного OpenDesign. Тесты и скриншоты обязательны на exact SHA; физический планшет и экранная клавиатура остаются NOT RUN до фактической проверки.
