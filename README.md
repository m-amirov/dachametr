## Локальный интерактивный прототип
- `src/domain/exact.ts` — рациональная десятичная арифметика без округления IEEE-754 в вычислениях.
- `src/domain/plot.ts` — чистый расчёт участка, слоёв, BOM, упаковок и ошибок без React/DOM.
- `tests/plot-domain.test.mjs` — тесты против независимых эталонов и отрицательных сценариев из `docs/specs`.
- `src/ui/model.ts` — предсказуемое draft-состояние со стабильными ID зон, слоёв и вариантов материалов.
- `src/ui/validation.ts` — адаптер строковой формы к доменному движку и fail-closed сообщения об ошибках.
- `src/ui/app.ts` и `src/styles.css` — task-first интерфейс «Измерительный инструмент» на vanilla TypeScript без UI-библиотеки.
- `tests/browser/prototype.spec.mjs` — критические сценарии в Chromium: BOM, запятая, fail-closed и клавиатурный фокус.
- `artifacts/ui-evidence/` — зафиксированные браузерные скриншоты и viewport-проверки после локальной приёмки.
- `.github/workflows/prototype-domain.yml` — CI домена, UI unit-тестов, сборки и Chromium E2E.

Запуск локального прототипа:

```text
npm ci
npm run dev
```

Проверки: `npm test`, `npm run build`, `npm run test:browser`. Обычный ввод хранится только в памяти текущей сессии и не восстанавливается автоматически после обновления страницы. Локальная функция «Скопировать ссылку» создаёт версионированный URL-фрагмент `#dm=1.…` с размерами, зонами и вариантами материалов — он **содержит пользовательские названия** и предназначен для осознанной передачи получателю. Фрагмент не отправляется серверу в обычном HTTP-запросе, но может быть виден получателю, в истории браузера и сервису обмена сообщениями. Открытие корректной ссылки восстанавливает расчёт только после строгой проверки; при редактировании старый фрагмент удаляется из адреса. Ссылка на `localhost` работает только там, где запущен локальный прототип, и **не является публичной ссылкой на dachametr.ru**. Внешние API, цены, нормы, авторизация, аналитика и публикация не подключены.

### Экспорт ведомости в CSV (локально)

- Кнопка **«Скачать CSV»** доступна только при завершённом корректном расчёте с материалами. Выгружаются отдельные строки по `material_spec_id`; излишки, закупленные упаковки и массы не домысливаются при отсутствующих параметрах. Расчёт использует существующий точный доменный движок.
- CSV создаётся **только в браузере**, без сервера, аналитики, внешней сети или сохранения файла на сайте. Имя: `dachametr-vedomost.csv`, кодировка UTF-8 с BOM, разделитель `;`, десятичная запятая и окончания строк CRLF. Это удобный для русскоязычного Excel формат; Google Sheets может потребовать явный выбор разделителя.
- Для защиты от формульных инъекций пользовательские названия с опасными ведущими символами `= + - @` экспортируются как текст, а переводы строк и управляющие символы нейтрализуются. Очень длинные десятичные величины (более 15 цифр) принудительно сохраняются как текст с префиксом-апострофом, чтобы Excel не округлил их молча; некоторые программы могут отображать этот апостроф буквально. При импорте чисел предельной точности указывайте тип столбца **Текст**.
- CSV не является сметой: цены, подрядные нормы и рекомендации о конструкции не подставляются.
