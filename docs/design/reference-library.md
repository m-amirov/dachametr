## Протокол работы
1. Перед следующей визуальной итерацией зафиксировать настоящие screenshots текущего браузерного HEAD и те же состояния из artifacts/ui-evidence. Отделять исходные данные от гипотез дизайнера.
2. Выбрать 2–3 **конкретные** карточки из галерей (URL + screenshot, дата/автор по возможности), описать элемент для переноса: компоновка/типографика/сетка/таблица/CTA, почему улучшит участок → зоны → слои → BOM.
3. Предложить 2–3 действительно разных макета (не только цвета). Сравнить первый экран, рабочую плотность и поведение результата на 390, 768, 1440 px.
4. До выбора владельца не заменять токены PR #7 из src/styles.css и не делать скрытый редизайн. Согласованный diff — отдельно.
5. После реализации: сравнить before/after initial, editing, error, result на 320/390/768/1024/1440 и 200% zoom; проверить Cyrillic fonts, console, image decode, keyboard, touch, caret и scroll. Без реального телефона/планшета оставить BLOCKED_DEVICE.

## Как выглядит не «AI-slop»
Индивидуальная предметная иерархия (измерительная шкала, объёмы, слои), достаточная плотность реальных данных, результат с расшифровкой, логичная сетка и намеренная типографика. Не использовать три одинаковых feature-card, fake testimonials/metrics, декор «листочки и градиент», размытые картинки, случайные иконки, огромные скругления, маркетинговый копирайт вместо инструмента.

## Что требуется от владельца для окончательного фирменного стиля
- 2–3 **конкретных визуальных примера/скриншота** из галерей, с пояснением, что нравится и не нравится. Это самый важный пока отсутствующий материал.
- Решение, оставляем ли тёплую палитру и системные шрифты PR #7, или хотим осознанный новый визуальный язык.
- Статус логотипа «Дачаметр» (пока допустим типографический знак; чужие ассеты не использовать).
- Физические mobile/tablet проверки для final QA; текущий Chromium evidence не заменяет их.

## Правовой и продуктовый scope
Не копировать в Git внешние screenshots/шрифты/макеты без проверки прав. Пока нет публичного release, SEO-страницы, DNS и РСЯ запрещены. Сами галереи нельзя трактовать как источник строительных норм или пользовательского спроса.
