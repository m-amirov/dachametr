# Cross-project regression register — предотвращаем повторы

Таблица основана на прежних пользовательских инцидентах и репозиторных правилах [Eskizno](https://github.com/m-amirov/eskizno), [Ludory](https://github.com/m-amirov/ludory), [Dzen Conveyor](https://github.com/m-amirov/dzen-conveyor), [task-playwright-desktop](https://github.com/m-amirov/task-playwright-desktop) и уже опубликованных фактах [Dachametr PR #2](https://github.com/m-amirov/dachametr/pull/2). Это **план предотвращения аналогичных дефектов**, а не подтверждение, что перечисленные неисправности существуют в Dachametr.

| Известный тип инцидента | Профилактика для Dachametr | Проверка, когда появится приложение | Ownership |
| --- | --- | --- | --- |
| Редизайн интерфейса игры уничтожил прежнюю визуальную иерархию, шрифты и CG/ассеты; мобильный crop и blur-fill испортили кадр | Сначала сохранить baseline и список существующих шрифтов/ассетов, не заменять их без scope/approval; подбирать contain/cover **по назначению контента**, проверять читаемость и пропорции | Снимки до/после 320/390/768/1024/1440, asset/font network and rendered-font audit, отзыв независимого визуального ревью | visual-craft, visual-qa, change-review |
| Изображения/ассеты загружались не сразу, были пустые кадры/ошибки декодирования, неверный path/encoding/MIME | Учитывать load/decode и 404/decoded image state, URL/percent encoding, CSP, MIME, path traversal; никакой silent placeholder при ошибке | Browser console/network; broken-images counter; test early/slow load/error/reload | engineering-quality, interaction-reliability |
| CRLF/LF ломал digest/CI и воспроизводимость сборки | UTF-8 + LF; stable serialization and explicit hashing of canonical bytes; не переписывать машинные данные «починкой кодировки» | repo/source checksum, actual build artifact identity; Windows-local vs CI только при релевантном различии | change-review, research-data-integrity |
| В Dachametr 5 918 U+FFFD в `keywords.csv`, прежний CI этого не видел | Strict decoding, U+FFFD rejection, original-source field equality, preserve raw artifacts and unknowns | CSV provenance/unit tests + published GitHub Raw check | research-data-integrity |
| В Eskizno на Huawei/Yandex Browser не срабатывала загрузка, верстка снизу съезжала, возникали перезагрузки | Проверять critical pointer/touch/file/scroll events по фактическому устройству, не считать desktop emulation реальным планшетом; сохранять ввод при переходе/focus/visibility | Physical-device repro, file-select change, scroll/pinch/zoom, page reload/back/restore + state persistence | interaction-reliability, visual-qa |
| Жесты/zoom/pan/drag взаимодействовали с редактором неожиданно | Separate hit targets, passive/pointer cancellation, prevent default only in bounded zone; undo/redo and route state explicit | Touch scroll vs calculator controls, focus while zooming, no accidental mutation | calculator-ux, interaction-reliability |
| Ludory: CI PASS без независимого browser/platform evidence, trust handoff и неверное объявление релиза | `PASS` только для реально наблюдаемого scope, exact SHA; `BLOCKED` и `NOT RUN` сохраняются; required gates перед publish | Browser/device E2E and prod smoke on exact build, logs, screenshots, receipts | change-review, release-readiness |
| Ludory: двусмысленные JSON ключи, import traversal, несовпадение validator/builder | Parse strict; reject duplicates/unsafe URLs and prototype pollution, raw user input — данные; validators должны тестироваться против ошибочных fixtures | Negative fixtures for duplicates, injected URL, malformed share URL; one normalization contract | engineering-quality, research-data-integrity |
| task-playwright: stale selectors, повтор неизвестно успешных действий, необузданные retries, потеря контекста | Никаких silent повторов внешнего действия; bounded recovery, durable intent and idempotency where needed. В MVP вообще нет внешних submit/API | Reload/back/restore, offline behavior, exact error state; do not invent success or auto-submit | interaction-reliability, release-readiness |
| Dzen: источники заменялись общим AI-текстом, шаблонными обобщениями и недостоверными изображениями | Claim registry, no fake norms/prices, тексты и изображения помогают понять задачу, не заполняют SEO объём | Manual factual/content review of each tool with source link and formula | content-integrity, technical-seo |
| Наращивание функций до закрытия состояния старого вертикального среза | Scope freeze and change-impact inventory, one independent vertical slice first, no opportunistic refactors | PR file diff, visual/behavior baseline, regression for touched functions | change-review, engineering-quality |

## Severity и fail-closed
- **P0:** неправильный или опасный ответ, потеря пользовательских данных, security regression, неверный публичный релиз.
- **P1:** неверное закупочное округление, утрата ключевых шрифтов/картинок, сломанный мобильный ввод, некорректный SEO canonical/indexing.
- **P2:** косметический дрейф, нефункциональные удобства, слабый контент без искажения ответа.
- Не вводить требования к Twork API/SDK, игровым платформам или Canvas-редактору: в Dachametr их нет. Переносить **тип риска**, не чужую архитектуру.
