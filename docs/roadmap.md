# Этапы работы

## Stage 0 — подготовка
Правила Codex, 9 локальных skills, источники, gates, проверки документов. Без автогенерации приложения и DNS.

## Stage 1 — доказать спрос
Реальные Wordstat + mobile/desktop SERP, кластеризация задач, выбор ~8–10 калькуляторов, GO/NO-GO/BLOCKED; затем спецификация первого.

## Stage 2 — дизайн и вертикальный срез
2–3 предметных дизайн-направления, утверждение токенов, один полноценный калькулятор; точная формула, тесты, все UI состояния, screenshots, независимый visual QA.

## Stage 3 — функциональный MVP
Реализация утверждённых инструментов, осмысленные SEO-страницы, shareable results, навигация, техническое SEO и тесты каждого расчёта.

## Stage 4 — развёртывание
Статический хостинг, HTTPS, redirects/canonicals, DNS, indexing и измерение только при разрешении владельца; продакшен smoke и gates.

## Stage 5 — продвижение по данным
Новые функции и тексты только по реальным поисковым запросам/пользовательским сценариям. РСЯ — только после возникновения реальной аудитории и прохождения модерации.
