# Wordstat и Webmaster: что измерено и как закрыть Gate 1

Дата актуализации: **13.11.2026**.

## Уже получено

В репозиторий перенесены несекретные результаты авторизованной сессии владельца:

- wordstat-observations.csv: 90 попыток измерения, 45 фраз × wide/кавычки;
- keywords.csv: 107 исходных seed-фраз и 80 строк с числовой частотностью;
- wordstat-dynamics.csv: 253 месячных значения для 11 прямых запросов;
- регион: Россия / все регионы;
- устройства: все;
- дата доступа: 13.11.2026;
- периоды в интерфейсе смешаны: 10.09–09.10.2026 и 12.10–12.11.2026.

10 попыток не получили числового значения. Пустое значение оставлено пустым; явный 0 сохранён как 0. Поле no_data — исторический флаг **пустой таблицы связанных запросов**, а не отсутствие основной частотности: 46 строк имеют no_data=true и числовую частотность, ещё 10 строк имеют no_data=true и пустую частотность. Для снятия неоднозначности добавлены frequency_status и no_data_scope.

Сохранённые CSV-файлы Wordstat находятся только в локальном каталоге исследования вне репозитория: найдено 23 файла — 12 table-выгрузок и 11 dynamic-выгрузок. Один table-файл (`q002-quotes.csv`) содержит только заголовок, хотя DOM observation хранит одну related-строку; это ещё одна причина не объявлять набор независимо воспроизводимым. В публичный PR перенесены производные несекретные строки, но не сессионные выгрузки. Поэтому один URL Wordstat подтверждает происхождение запроса, но не делает исходный CSV независимо воспроизводимым.

## Исправление целостности keywords.csv

Первопричина установлена на уровне Git-истории: blob `keywords.csv` в `83d7f053` содержит корректные UTF-8 seed-запросы, а при подготовке `12ff4e5` файл был перезаписан результатом lossy-преобразования с буквальными U+FFFD. Точный инструмент/локальная кодировка промежуточной операции из Git не восстанавливаются; это не было исправлено обратной заменой символа. 107 seed-строк взяты из `83d7f053`, а 80 измеренных строк — из сохранённого Wordstat observation-слоя. Валидатор теперь проверяет strict UTF-8, U+FFFD, уникальные ключи и полное соответствие измеренных строк observation-источнику.

## Что остаётся недоступным

- Октябрь 2026 в 24-месячной динамике: сохранённая выгрузка фактически содержит ноябрь 2024 — сентябрь 2026. Причина отсутствия не установлена: по имеющимся CSV/raw-артефактам нельзя различить непубликацию месяца источником и ошибку извлечения. Это не следует трактовать как доказательство ни одной из этих причин; месяц не заполняется нулём.
- Стабильные ряды по каждому приоритетному кластеру.
- Разрезы Wordstat по mobile/desktop, если они нужны отдельно от «все устройства».
- Яндекс Вебмастер: спрос, клики, конкурентность, популярные страницы конкурентов и региональные различия.
- Связь частотности с реальными CTR и трафиком нового домена.

До получения этих данных Gate 1 не переводить в GO.

## Безопасный формат экспорта

В публичный репозиторий переносить только несекретные строки:

- query;
- cluster/direction;
- region;
- period, period_start, period_end;
- operator: wide или quotes;
- frequency; если интерфейс не дал число — пусто;
- no_data: true/false — legacy-флаг пустой таблицы связанных запросов;
- frequency_status: measured_numeric, main_value_not_returned или not_measured;
- no_data_scope: related_queries;
- source_url с точным URL Wordstat;
- checked_at;
- notes с предупреждением интерфейса и ограничениями.

Не переносить cookies, токены, выгрузки аккаунта, персональные данные и скриншоты с приватной информацией. Вход выполняет владелец в своей сессии; обход авторизации, CAPTCHA или ограничений запрещён.

## Повторяемая процедура Wordstat

1. Открыть официальный [Wordstat](https://wordstat.yandex.ru/) в своей авторизованной сессии.
2. Выбрать регион «Россия» и отдельно сохранить выбранный режим устройств. Не смешивать «все» с mobile/desktop.
3. Проверить seed-фразы из keywords.csv и расширить их только реальными формулировками из таблицы Wordstat.
4. Для каждой task-aligned фразы сохранить wide и кавычки отдельными строками; оператор должен быть частью идентичности наблюдения.
5. Сохранить текущую частотность, период, дату доступа и точный URL. Если Wordstat сообщает о временной недоступности, сохранить это в notes.
6. Для 11 прямых запросов из wordstat-dynamics.csv получить динамику с диапазоном, включающим октябрь 2026. Если сервис снова отдаёт неполный ряд, указать фактический диапазон.
7. Не суммировать вложенные широкие фразы, related rows, wide и quotes. Для приоритета использовать максимум одной фразы как ориентир, а не «объём кластера».
8. Сверить дубликаты по query + cluster + operator + region + period.
9. Для публичного PR передавать только производные строки; локальные CSV-выгрузки считать evidence-only и не объявлять независимо воспроизводимыми без опубликованного несекретного артефакта.

## Яндекс Вебмастер

Открыть официальный инструмент [«Подбор поисковых запросов и анализ рынка»](https://yandex.ru/support/webmaster/ru/service/queries-selection) и получить для shortlist-кластеров:

- регион;
- устройство;
- период и дату выгрузки;
- спрос;
- клики;
- конкурентность;
- популярные страницы конкурентов.

Метрики Webmaster не смешивать с частотностью Wordstat. Проверку URL dachametr.ru выполнять только после подтверждения домена владельцем; до этого использовать рыночный/региональный режим без выдуманных данных.

## Критерий закрытия

23 доступных месяца уже позволяют сделать **предварительное описательное** сравнение сезонности: ряд покрывает почти два годовых цикла, а пропуск октября 2026 находится на конце диапазона, а не внутри наблюдаемой истории. Но это не полный 24-месячный доказательный ряд и не позволяет подтвердить октябрьский переход или полный year-over-year цикл. Для финального market GO нужны: Webmaster-метрики по shortlist, минимум один новый региональный и один mobile SERP-срез, объяснённый статус октябрьского месяца и пересчитанный рейтинг с отдельными неизвестными.
