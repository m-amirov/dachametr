# Предварительная матрица направлений (НЕ утверждённый MVP)

13.11.2026, региональная выдача Яндекс — Пермь, дополнительные публичные страницы. Нет Wordstat, 24-месячной сезонности, федеральной срезки, ни выборки реальных пользователей. **Поэтому ранжирование ниже основано на реализации и дифференциации, а не на измеренном спросе.**

## Принципы приоритизации
- **Релевантность utility-сайту**: можно получить конкретное закупочное решение.
- **Проверяемость метода**: чистая геометрия и нормы по явному вводу проще и безопаснее неподтверждённых рекомендаций.
- **Возможность улучшения**: не просто дублировать Gazon52, Calcup или SimGarden, а связать данные между разными расчётами и дать лист материалов.
- **Издержки разработки**: простые клиентские формулы в приоритете; сложные схемы только с проверкой UX.
- **Поисковый спрос и достижимость**: пока UNKNOWN, без искусственного числа/балла. Когда будут Wordstat и конкурентность из Вебмастера, пересчитать приоритет.

## Что не добавлять в первую очередь
- **NPK и дозы удобрений:** агрономическая достоверность, концентрации N/P₂O₅/K₂O, анализ почвы; без источников пользователю нельзя обещать норму подкормки. Можно позже сделать чистый пересчёт массы удобрения по известной целевой дозе.
- **Глубокий расчёт напора/насоса:** гидравлика, реальные потери давления и неверные рекомендации по оборудованию.
- **«Калькулятор цены без цены» и фиктивные регионы:** цену вводит пользователь либо используется проверенный текущий прайс с датой.
- **Микространицы по каждой сотке, числу растений и «калькулятор на 10 м²».** Параметры остаются внутри одной страницы или shareable URL с canonical на базовый инструмент.
- **Тонны SEO-текста:** форма + расчёт + метод + ограничения важнее количества слов.

## Гипотеза дифференциации
Вместо каталога взаимозаменяемых форм сделать взаимосвязанный **проект участка без аккаунта**: площадь → зоны → расчёты грунта/мульчи/семян/полива → единый список закупки, сохранение ссылкой/печать. Риск: это дополнительная UX-разработка, которая не подтверждена пользовательскими исследованиями. Поэтому начать с независимого вертикального среза и проверить удобство.

## Решение
Не фиксировать 10 «победителей» без спроса. По измерениям Wordstat и Вебмастера можно сместить первые позиции или вообще отказаться от части кластера.
