## Решение владельца: локальный Prototype Gate

- **2026-11-13 / AUTHORIZED LIMITED.** Владелец подтвердил объединение PR #4 и разработку одного локального прототипа в ответ на предложение утвердить PR #4 и отдельно разрешить локальный прототип. Спецификация — `docs/specs/plot-zones-materials-v0.md`, `draft-v0.5`, утверждённая как **граница инженерной реализации**, а не как доказательство пользовательского спроса или готовый дизайн.
- **Точный разрешённый scope:** прямоугольный участок, до 50 прямоугольных зон/10 слоёв на зону, грунт/песок/щебень с явным различением сортов/фракций по `material_spec_id`, расчёт площади, слоёв, запаса, optional density/package, BOM с округлением общих сопоставимых позиций и отдельными требуемыми/закупочными величинами; точная decimal арифметика, проверка ошибок и локальный UX.
- **Порядок:** сначала чистый TypeScript domain engine с golden fixtures и CI; дизайн-направление, палитра и шрифты ещё не выбраны — отдельная визуальная приёмка до UI-ready.
- **Запреты:** не деплоить, не публиковать, не индексировать, не создавать сотни SEO URL; не менять DNS/robots, не подключать РСЯ/аналитику/трекинг; никакой обязательной сети, аккаунтов, БД, backend AI, сторонних автоматически исполняемых skills или массового рефакторинга.
- **Сохранённые gates:** Market Gate 1 = BLOCKED, G2/G3 до фактических тестов NOT RUN, G4 browser/device до UI NOT RUN, G8 release = NOT AUTHORIZED, G9 = N/A. Разрешение не является одобрением `main` merge любых будущих PR.
