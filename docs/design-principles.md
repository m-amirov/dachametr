# Дизайн Дачаметра — уникальность и полезность

«Дачаметр» — **калькуляторный сервис**, не конверсионный SaaS-лендинг. Формы и результаты доминируют; верх страницы не занят длинным hero, вымышленными отзывами или декоративными метриками.

## Характер
Спокойный профессиональный инструмент с узнаваемой дачной предметностью. Допустимы схемы участка, разметка грядки, слои грунта, визуализация полива, когда они помогают **считать**, а не украшают. Палитру и шрифты нельзя автоматически копировать из внешних skills: сначала 2–3 различных обоснованных направления, затем выбранные токены.

## Обязательные детали
- Семантические цвета, spacing/typography, состояния default/focus/disabled/error/result.
- Чёткие физические единицы: м, м², м³, л, сотка, кг, г; формат чисел ru-RU и понятная точность.
- Настоящие label, fieldset, текстовые подсказки, visible focus, keyboard navigation, не передавать смысл одним цветом.
- Целевой контраст WCAG AA: 4.5:1 обычный текст, 3:1 крупный. Touch targets по возможности >=44×44 CSS px.
- Проверить 320/390/768/1440 CSS px, zoom 200%, длинный русский текст, ошибки и итог. Поддержать reduced motion.
- Результат никогда не заслонён popups или рекламой; не добавлять бессмысленные анимации.
- Без типового триплета одинаковых карточек, абстрактных градиентов, бейджа над каждым заголовком, стоковых AI-листочков, эмодзи вместо иконок.

## Рабочий цикл
Сравнить направления → утвердить токены → сделать один полноценный калькулятор/компоненты → записать screenshots текущего браузерного рендера с состояниями → провести независимую визуальную критику → масштабировать после исправлений.
