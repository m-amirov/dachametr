## 7. Жизненный цикл, состояния и целостность
- Raw-значение вводимого текста (запятая, незавершённый ввод, caret/focus); преобразование в число только после валидации.
- Back/forward, reload, смена единиц и зон, share URL с версией схемы, неверная/повреждённая ссылка, отключение сети после загрузки.
- Источник истины для React/URL/local state; не размещать PII в query string; политика восстановления.
- Округление на уровне каждой упаковки vs общего результата, обоснование запаса/плотности, пользовательский ввод нормативов.
- Границы: пусто, 0, дробь, отрицательное, infinity/NaN, экстремальные числа, ru-RU comma/dot, несколько разделителей.

## 8. Доказательная приёмка
| Контроль | Что фиксируется |
| --- | --- |
| Golden tests | Независимые ожидаемые значения, формула, размерности, RED/GREEN |
| Property tests | Монотонность, масштабирование, перестановка зон, unit conversion, boundary ceil |
| Browser QA | Браузер/viewport/DPR/SHA, empty/editing/error/result, клавиатура, touch, back/reload |
| Assets & fonts | Font load, кириллические glyphs, broken images, MIME и decode, права |
| SEO | Canonical route, actual HTML, неиндексируемые query variants |
| Privacy | Нет секретов/PII/неразрешённой telemetry |
До реальной сборки browser/performance/SEO = NOT RUN, не PASS.
