# Gate 1 — проверка рынка до разработки

## Порядок
1. Собрать реальные данные Wordstat/Вебмастер по РФ с точным регионом/периодом и 24-месячной сезонностью. Ориентир: 100–200 релевантных запросов, не искусственная квота.
2. Группировать по отдельным user jobs, не по вариантам слов «расчёт», «калькулятор», «сколько нужно».
3. Изучить свежие mobile/desktop SERP и **работающие** конкурентные калькуляторы: поля, UX, вывод, формулы, полезность. Открыть и проверить страницы, сохранить URLs и дату.
4. Разделить фактически полученные частотности и экспертные предположения. Если Wordstat недоступен, указать BLOCKED_WORDSTAT_ACCESS.
5. Применить прозрачную таблицу приоритетов: подтверждённый спрос, достижимость, удобство, возможность дать больше конкурентов, сложность и надёжность расчёта, сезонность.
6. Подготовить обоснованный список ~8–10 разных калькуляторов **только после** данных.

## Артефакты доказательств (не заполнять фиктивными строками)
- docs/research/keywords.csv: query,cluster,region,period,frequency,frequency_definition,source_url,accessed_at,notes
- docs/research/serp-review.md: изученные страницы конкурентов, URLs, состояние, скриншоты/дата.
- docs/research/mvp-prioritization.md: расчётный приоритет, причины и отвергнутые направления.
- docs/research/gate-1-decision.md: GO / NO-GO / BLOCKED, конкретные свидетельства.

## Результат
**GO:** несколько доказанных достижимых кластеров; каждый инструмент решает самостоятельную задачу и имеет проверяемую методику. **NO-GO:** запросов недостаточно или нет убедимого отличия от SERP/конкурентов. **BLOCKED:** нет данных, инструментов или источников. Ни один результат не обещает SEO-позиций и дохода.
